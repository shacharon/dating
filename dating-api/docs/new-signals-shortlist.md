# New signals shortlist (next phase)

Spec for four candidate signals to add in a future extraction phase. **Not wired into scoring yet.**

---

## 1. conflictStyle

| Field | Content |
|-------|--------|
| **Signal name** | conflictStyle |
| **What it captures** | How someone tends to handle disagreement: avoidant vs confrontational vs collaborative vs "talk it through." |
| **Why it matters** | Mismatches (e.g. one needs to hash it out, the other shuts down) drive daily friction; alignment reduces conflict escalation. |
| **Example trigger phrases** | "talk things through," "no drama," "don't like confrontation," "hash it out," "need time to cool off," "avoid conflict," "direct when we disagree," "prefer to discuss calmly." |
| **Distinct from** | directness (day-to-day communication style); attachmentSecurity (bonding style). Conflict style = behavior when there is actual disagreement. |
| **Priority** | **HIGH** |

---

## 2. noveltyVsRoutine

| Field | Content |
|-------|--------|
| **Signal name** | noveltyVsRoutine |
| **What it captures** | Preference for novelty, spontaneity, and change vs routine, predictability, and structure in daily life and plans. |
| **Why it matters** | Drives compatibility in how couples plan weekends, travel, and handle "same vs new"; large gaps cause frustration. |
| **Example trigger phrases** | "love spontaneity," "routine person," "need predictability," "same coffee place every day," "always trying something new," "surprise me," "structured week," "go with the flow," "plan everything." |
| **Distinct from** | lifestylePace (slow vs fast); independence (space/autonomy). This is content of life (same vs new), not speed or alone-time. |
| **Priority** | **HIGH** |

---

## 3. intellectualCuriosity

| Field | Content |
|-------|--------|
| **Signal name** | intellectualCuriosity |
| **What it captures** | Importance and style of intellectual engagement: loving ideas, learning, debate, books, "deep conversations" vs preferring practical or light topics. |
| **Why it matters** | Often a stated desire ("someone I can talk to for hours"); mismatch leads to boredom or pressure on one side. |
| **Example trigger phrases** | "love deep conversations," "curious about everything," "read a lot," "into ideas," "philosophy," "not into small talk," "learn together," "debate," "abstract thinking," "practical, not a big reader." |
| **Distinct from** | emotionalDepth (emotion and vulnerability); this is about ideas and intellect. |
| **Priority** | **HIGH** |

---

## 4. structureChaosTolerance

| Field | Content |
|-------|--------|
| **Signal name** | structureChaosTolerance |
| **What it captures** | Tolerance for mess, unpredictability, and loose structure in life (home, schedule, plans) vs need for order and clarity. |
| **Why it matters** | Cohabitation and daily friction; "chaos-tolerant" vs "needs order" is a common couple complaint. |
| **Example trigger phrases** | "organized," "need order," "mess doesn't bother me," "go with the flow," "structured," "flexible with plans," "clean home matters," "organized chaos," "last-minute plans are fine." |
| **Distinct from** | lifestylePace (speed); noveltyVsRoutine (same vs new). This is order vs mess and plan rigidity. |
| **Priority** | **HIGH** |

---
