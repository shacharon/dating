# Beta user list template

**Do not commit real names/emails to git.** Copy these columns into a private spreadsheet (Google Sheet / Notion).

## Target profile

- Location: Tel Aviv (metro OK)
- Age: ~28–40
- Intent: serious relationship (not casual-only)
- Sources: personal network, friends-of-friends, local groups

## Columns

| Name | Email | Source | Status | Invited at | Signed up | Notes |
|------|-------|--------|--------|------------|-----------|-------|
| | | personal / fb / reddit / linkedin / other | prospect / invited / signed_up / churned | | Y/N | |

**Target:** ~100 sign-ups by end of Week 1 (stretch; friends wave first).

## Status values (suggested)

- `prospect` — identified, not invited
- `invited` — email sent
- `signed_up` — Google account created
- `churned` — invited, no activity after 7d
- `declined` — said no

## Privacy

Treat the sheet as PII. Limit editors. Do not paste rows into Slack/git/PRs.
